== Description ==

Monevibe Affiliate Tracker is a lightweight solution designed to help store owners track affiliate conversions. It automatically captures click identifiers from your marketing URLs and links them to WooCommerce orders.

== Installation ==

1. Go to **Plugins > Add New** in your WordPress dashboard.
2. Upload the `monevibe-tracker.zip` file.
3. Click **Activate**.
4. That's it! The plugin starts tracking automatically.

== Frequently Asked Questions ==

= Does it affect site performance? =
No, the plugin is extremely lightweight and only runs during specific order events.

= Where can I see the Click ID? =
You can find the Click ID inside each order details page in the WooCommerce admin panel.
